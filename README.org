* copilot-chat-completions is a script to provide good old OpenAI-like REST stateless chat user interface to LLMs
version: 0.1
* Usage
To run:
: PYTHONPATH="/path-to/copilot-sdk/python" uvicorn server:app --host 127.0.0.1 --port 8000 --reload
To Test:
#+begin_src bash :eval no :exports code :results none

curl --request POST \
  --url http://localhost:8000/v1/chat/completions \
  --header 'content-type: application/json' \
  --data '{
    "model": "gpt-4.1",
    "messages": [
      {"role": "user", "content": "Explain async functions in Python."}
    ]
  }'
#+end_src
